저장하는 정보와 목적

별명, 독서 레벨, 지역 선택, 읽은 책과 날짜를 저장해 독서 기록과 맞춤 추천을 제공합니다. 실명 대신 별명을 사용해 주세요.

저장 위치와 외부 전송

안드로이드·아이폰 앱은 데이터를 기기 내부에 저장합니다. 회원가입, 광고, 분석·추적 SDK를 사용하지 않으며 운영자 서버로 전송하지 않습니다. 안드로이드는 자동 클라우드 백업과 시스템 기기 이전을 사용하지 않습니다. 아이폰은 프로필·독서 기록 저장 파일을 시스템 자동 백업 대상에서 제외합니다. 필요한 기록은 앱에서 직접 내보내 주세요. 연락처·사진·카메라·마이크 또는 광고 식별자에 접근하지 않습니다.

가까운 도서관 지역 선택

처음 지역을 설정하거나 현재 위치 찾기를 누르면 선택적으로 대략적인 위치 권한을 요청합니다. 허용 시 앱을 사용하는 동안 위치를 한 번 확인하여 서울·성남·용인·수원·부산의 도시 중심 중 가까운 곳을 선택합니다. 좌표는 계산 중 메모리에서만 사용하며 저장·백업하거나 운영자 서버로 전송하지 않습니다. 선택한 도시만 프로필에 저장합니다. 백그라운드 위치 추적을 하지 않습니다. 권한을 거부하거나 위치를 확인하지 못해도 지역을 직접 선택하고 모든 기능을 사용할 수 있습니다. 기기의 설정에서 위치 권한을 철회할 수 있습니다.

외부 사이트와 백업

도서관 등 외부 링크는 브라우저로 열리며 해당 사이트 정책이 적용됩니다. 백업을 내보내면 사용자가 선택한 위치에 JSON 파일을 저장합니다. 클라우드 저장 위치를 선택하면 해당 저장 서비스 정책이 적용됩니다.

보유 기간과 삭제

사용자가 삭제할 때까지 보관합니다. 설정에서 프로필별 삭제 또는 전체 삭제가 가능하며 앱 삭제 또는 안드로이드의 앱 데이터 삭제 시 기기 내부 기록도 삭제됩니다. 내보낸 백업 파일과 클라우드 사본은 사용자가 저장 위치에서 별도로 삭제해야 합니다.

어린이와 보호자

초등학생과 보호자가 함께 사용할 수 있습니다. 프로필에는 실명이나 생년월일·학교 등 식별 정보를 넣지 않는 것을 권장합니다. 보호자는 기기에서 프로필과 기록을 확인·수정·삭제하고 백업 파일을 관리할 수 있습니다.
